# LingoLab — сайт для изучения английского

Учебный проект на **Node.js + Express**, HTML, CSS и JavaScript. Express — фреймворк, а Node.js — среда, в которой работает сервер.

## Как запустить

### 1. Установи Node.js

Открой **https://nodejs.org/** и скачай версию с отметкой **LTS**. Подойдёт Node.js 22 или новее. npm устанавливается вместе с Node.js. После установки перезапусти терминал или VS Code.

Проверь установку:

```bash
node -v
npm -v
```

Обе команды должны показать номер версии.

### 2. Открой папку проекта

Распакуй `lingolab.zip`. Найди папку `lingolab`, внутри которой есть `package.json`.

Если используешь VS Code:

1. Выбери «Файл → Открыть папку» и открой именно `lingolab`.
2. Выбери «Терминал → Создать терминал».
3. Выполняй команды ниже в этом терминале.

Если терминал открыт в родительской папке, сначала выполни:

```bash
cd lingolab
```

### 3. Установи зависимости

```bash
npm install
```

Нужен интернет. Это скачает Express и его зависимости в `node_modules`. Обычно команду достаточно выполнить один раз.

### 4. Запусти сервер

```bash
npm start
```

Ты увидишь сообщение:

```text
LingoLab is ready: http://localhost:3000
Press Ctrl+C to stop.
```

### 5. Открой сайт

Введи в адресную строку браузера:

**http://localhost:3000**

Терминал должен оставаться открытым. Для остановки нажми **Ctrl+C** в терминале. В следующий раз достаточно открыть папку проекта и выполнить `npm start`.

Не открывай `index.html` двойным щелчком: сайту нужен запущенный сервер.

## Что есть на сайте

- **Overview** — главная страница, прогресс, цель на день и слово дня.
- **Word cards** — 24 слова по трём темам: повседневная жизнь, школа и путешествия. Нажатие на карточку показывает перевод и пример. `I know this word` отмечает слово как выученное; повторное нажатие убирает отметку.
- **Practice → Word check** — 6 случайных вопросов по словам.
- **Practice → Grammar lab** — 6 случайных вопросов из банка из 12 заданий. После ответа появляется объяснение.
- **Build a sentence** — 6 предложений. Нажимай на слова в нужном порядке; нажатие на выбранное слово убирает его. После сборки нажми `Check sentence`.
- **My project** — простой текст для защиты, перевод, объяснение технологий и ответы на возможные вопросы учителя.
- **RU hints** — включение и выключение русских подсказок. Переводы, необходимые для самих заданий, остаются видимыми.
- Кнопка с динамиком — произношение средствами браузера. Доступность и качество голоса зависят от браузера, системы и установленного английского голоса. Иногда голосу нужен интернет. Если озвучка не работает, можно пользоваться транскрипцией.

Прогресс сохраняется в **localStorage этого браузера**. Аккаунт и база данных не нужны. При смене браузера или адреса сайта будет другой прогресс. Очистка данных браузера удалит результаты.

Цель на день — 5 действий: отметить слово как выученное, правильно ответить в тесте или впервые собрать предложение. Это число действий, а не число уникальных слов. Дата берётся с твоего компьютера. Результат теста сохраняется после нажатия `See my results`; незавершённый тест не считается пройденным. Хранятся последние 100 тестов.

## Как связан проект с ChatGPT

ChatGPT помог написать код, оформить интерфейс, подготовить материалы и объяснение проекта. Сам сайт работает с готовыми заданиями. Он не подключается к ChatGPT API, не требует API-ключа и не генерирует ответы во время использования.

## Какие файлы за что отвечают

| Файл | Что делает простыми словами |
| --- | --- |
| `server.js` | Запускает сервер Express и отправляет браузеру файлы и материалы. |
| `public/index.html` | Содержит основу страницы. |
| `public/styles.css` | Задаёт цвета, размеры и расположение элементов. |
| `public/app.js` | Показывает разделы, реагирует на кнопки, проверяет ответы и сохраняет прогресс. |
| `data/content.json` | Хранит слова, переводы, примеры, вопросы и предложения. |
| `package.json` | Описывает проект, команды запуска и зависимости. |
| `package-lock.json` | Фиксирует конкретные версии зависимостей. |
| `PRESENTATION.md` | Содержит простой текст на английском и его перевод. |
| `test/app.test.js` | Автоматически проверяет сервер и учебные материалы. |
| `test/client.test.js` | Проверяет логику карточек, тестов, предложений и сохранения прогресса без браузера. |

Как проходит запрос:

1. Ты открываешь `localhost:3000`.
2. Сервер отдаёт HTML, CSS и JavaScript.
3. JavaScript получает материалы по адресу `/api/content`.
4. Когда ты нажимаешь кнопку, JavaScript меняет страницу и проверяет ответ.
5. Прогресс записывается в localStorage браузера.

## Если что-то не работает

**«node не является внутренней или внешней командой» / «command not found»**

Установи Node.js, затем полностью закрой и открой терминал. Если не помогло — перезапусти компьютер.

**PowerShell пишет, что выполнение сценариев запрещено**

На Windows можно использовать `npm.cmd install` и `npm.cmd start` вместо `npm install` и `npm start`. Другой вариант — открыть терминал **Command Prompt / cmd**. Менять настройки безопасности не нужно.

**npm не находит package.json**

Ты находишься не в той папке. Открой папку `lingolab`, где лежит `package.json`.

**Браузер не открывает сайт**

Проверь, что `npm start` продолжает работать и что ты открываешь `http://localhost:3000`, без `https`.

**Порт 3000 занят / EADDRINUSE**

Останови уже запущенный сервер через Ctrl+C в его терминале. Можно также выбрать другой порт:

Windows PowerShell:

```powershell
$env:PORT=3001
npm.cmd start
```

Windows cmd:

```bat
set PORT=3001
npm start
```

macOS / Linux:

```bash
PORT=3001 npm start
```

После этого открой **http://localhost:3001**.

**Я изменил код, но сайт выглядит по-старому**

После изменения `server.js` или `data/content.json` останови сервер через Ctrl+C и запусти снова. После изменения файлов в `public` обнови страницу; если нужно, нажми Ctrl+F5 (на Mac — Cmd+Shift+R).

## Проверки проекта

```bash
npm test
```

Проверяются загрузка страницы, выдача материалов, доступность CSS/JavaScript, недоступность служебных файлов, согласованность заданий и логика действий пользователя. Эти тесты не заменяют визуальную проверку в браузере. Для запуска сайта проходить тесты вручную не нужно.

## Перед защитой

1. Запусти сайт заранее и открой его в браузере.
2. Потренируйся объяснять каждую фразу из `PRESENTATION.md`.
3. Покажи одну карточку, один ответ в тесте и одно собранное предложение.
4. Обнови страницу, чтобы показать сохранение прогресса.
5. Если нужен чистый старт, открой `My project → Reset progress` и подтверди сброс.

Основная работа сайта после установки не требует интернета. Внешние шрифты, картинки и платные API не используются. Озвучивание зависит от голоса в браузере, поэтому проверь его заранее.

Официальные справки: https://nodejs.org/en/download и https://expressjs.com/en/starter/installing/.
