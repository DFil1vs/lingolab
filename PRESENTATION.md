## Текст целиком

This is my English learning website. Its name is LingoLab. I made this project with ChatGPT. It has word cards, quizzes and sentence tasks. You can see a translation and an example. The website checks your answers. It saves your progress in the browser. Node.js and Express run the local server. HTML gives the page its structure. CSS makes it look nice. JavaScript makes the buttons work. This project shows how AI can help us learn.

## Что показывать на экране

1. На фразе **“This is my English learning website”** покажи главную страницу.
2. На **“It has word cards…”** открой Word cards и переверни карточку.
3. На **“The website checks your answers”** открой Practice → Word check и ответь на вопрос.
4. На **“It saves your progress”** отметь слово как выученное, затем обнови страницу: отметка сохранится.
5. Когда говоришь о технологиях, открой раздел My project.

## Если учитель задаст вопросы

**Why did you choose this project?** — Почему ты выбрал этот проект?

I wanted to make a simple and useful tool for learning English.

Я хотел сделать простой и полезный инструмент для изучения английского.

**How did ChatGPT help you?** — Как тебе помог ChatGPT?

ChatGPT helped me write the code, design the pages and create the exercises.

ChatGPT помог написать код, оформить страницы и создать задания.

**What is localhost?** — Что такое localhost?

It is an address for a server on my own computer.

Это адрес сервера на моём компьютере.

**Where is the progress saved?** — Где сохраняется прогресс?

It is saved in localStorage in this browser.

Он сохраняется в localStorage этого браузера.

**Does the website use ChatGPT live?** — Сайт обращается к ChatGPT во время работы?

No. ChatGPT helped build the project. The website uses prepared lessons.

Нет. ChatGPT помог создать проект. Сайт использует готовые учебные материалы.
